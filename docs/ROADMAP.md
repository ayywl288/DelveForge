# 当前里程碑

交付一个支持多提供方的项目 Coding Agent 工作台。唯一支持的路径为 Project → Conversation → Run。现有项目、对话、工作副本、检查点和工具证据须跨版本保留。

## 验收条件

- 空项目创建、本机导入、项目切换、同对话追加要求和对话历史可通过实际工作台使用。
- Read、Edit、Write、Bash 在项目环境内执行。并行、取消、暂停、核对和恢复遵守项目占用与工具回执约束。
- 八个提供方通过 Spring AI 调用支持工具的模型。模型配置在入队时冻结，模型切换保留历史证据，兼容性状态可按账户和思考强度验证。
- Windows 本机可管理密钥和区域端点。密钥与厂商私有重放材料不进入公开时间线、工具输出或浏览器存储。
- 从已发布的工作台数据库升级可保留原记录，新装可独立启动。后端验证、前端类型检查、生产构建及工作台回归通过。供应商实测和需另外准备的容器环境分别记录。
