# ADR-0033　通过工作台公开接口评测 Coding Agent

SWE-bench Multilingual 的评测使用专用本机工作台安装。外部 Python Runner 导入单提交基线，通过 Project、Conversation、Run 接口提交官方问题并采集公开证据。每次试验绑定独立项目、容器、模型配置和预算。Agent 的指令、工具准入、历史投影及恢复沿用产品路径。

评分资产由宿主持有。Runner 在前台执行结清后停止所属开发容器，从工作副本生成相对原基线的补丁，以独立索引回放并核对 Git tree。官方评分器在另一容器中裁定补丁。报告分别统计官方解决率和预算内的自主成功率，保留未准入任务、基础设施异常与观察中断。

项目专用出站代理允许固定的软件源域名，保留现有私网及实际目的地址限制。包仓库仍可能提供新版本源码。该边界适用于可安装依赖的本地实验；需要严格离线隔离时，应另行固定工具链及全部依赖。首次校准使用单次尝试，后续对配置或网络策略的更改应作为新的实验记录。

首次基线按每道准入题的一个有效 Run 统计内部解决率。基础设施中断单列，同一 Run 的产物恢复沿用原身份。固定版本、预算和复现命令见[评测说明](../../eval/README.md)。本次六题的官方评分、分母和证据出处见[基线记录](../../eval/RESULTS.md)。
