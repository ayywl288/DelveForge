# ADR-0028　项目对话与共享开发环境

日期为 2026-11-14。用户已批准本决定。阶段 0 的运行事实见下节。旧发布及其历史记录继续按原合同解释。

## 决定

用户新建或导入 Project，取得一份独立、长期、可用 Windows 编辑器打开的工作副本。每个 Conversation 独立保存消息，同项目对话共享当前文件。用户发送任务授权本次 Run，后续消息能纠正同一对话的执行。当前版本共享环境同时接纳一个前台 Run，项目归属由控制端检查。后台服务可持续运行。工作副本就是结果，解释和只读调查也可正常结束。

Java 控制端负责持久记录、授权、调度、费用、上下文和恢复。Vue 展示事实和操作。新路径使用独立数据库和工作副本父目录。已发布的 Plan、Step、Candidate、Delivery 扫描及接受事务不接收新对象。旧授权不能转换成项目写授权。

Linux 开发容器只绑定工作副本父目录，另有持久数据卷。开发容器的可写系统层保存安装的软件。同容器停启保留该层，重建须重新安装。项目依赖使用各自项目的解析目录，下载缓存可复用。原始仓库、控制数据库、模型凭据和 Docker 管道留在宿主控制侧。同一权限下不同项目是逻辑分区。平台重启要先核对前台执行，重启环境会终止后台进程。

Windows 通过 Docker Desktop 的当前 Linux 命名管道使用 docker-java 3.7.1 与 HttpClient 5。开发容器加入没有宿主桥地址的内部网络。Squid 在独立受信网络空间限制公共 HTTP/HTTPS 实际目的地址，转发链关闭。宿主 DNS 提供合成保留地址的情况下，代理可使用经过证书验证的公共 HTTPS DNS。Go 网关只处理已登记的 HTTP/WS 预览与有限查询转发。它共享开发网络空间以核对监听 socket 身份，进程、文件及控制私钥隔离。Windows 回环入口通过两条固定 TCP 转发连接预览及双向 TLS 控制端。Java 经认证连接处理查询，按当前 invocation 确定项目和对话。

Read、Edit、Write 和 Bash 均在这一开发环境内执行。每次 Bash 启动新的 shell。工具结果保存原调用 ID、参数、实际输出和证据缺口。新输入先持久确认，未开始的工具和最终答复提交与输入在短事务中排序。中断后先确认存活事实，不重跑未知命令。确认已结束后可释放占用，退出码可以未知。同步语义压缩只改变送给模型的上下文视图，保留原始记录及协议字段。预算暂停可显式继续。

## 阶段 0 的本机观察

- Docker 29.4.0、API 1.54、linux/amd64。Windows Java 21 经命名管道取得真实 stdout、stderr 和退出码 17。
- 临时源目录更名后，副本离线通过 git fsck 并独立提交。验证了非默认分支、分离 HEAD、未出生分支、修改、删除、未跟踪、忽略配置、CRLF、生成依赖排除。源中途变动及外部 junction 均未产生 READY 副本。
- 真实 Windows Edge 读到 Java 响应，WebSocket 返回 101。默认监听漏掉 Windows 保存，单项目轮询使 Vue HMR 更新且保留点击次数和页面实例。Linux 生产构建含新文本。端口复用后旧 URL 返回 410，替代服务只收到新 URL 的请求。401、302 与跨项目端口占用 409 均经实测。
- Squid 7.6 拒绝保留地址。宿主 DNS 和普通公共 UDP DNS 都返回 198.18/15，TLS DNS 返回公共地址后，Git HTTPS、Maven Wrapper 和依赖、npm、pnpm、原生 esbuild、apt 均成功。开发容器无默认路由或网络管理能力，直连公共和私网目标失败，代理对私网和回环返回 403。匿名控制连接被拒绝。有限查询对授权历史与输出返回 200，跨项目 404，失效凭据 403，写入 405。
- figlet 2.2.5-3 实际在 A、B、A 连续执行，各项目 SQLite 服务数据独立，A 的 Java 服务持续可用。同容器停启保留 figlet，后台 API 已结束。重建移除系统安装，工作副本、Linux 项目依赖和数据卷保留。
- 控制进程在分配后、执行中及输出完成后断开。中途仅保留 OUT01、ERR01，原执行结束后可取得 17。两次产生效果的命令各追加一次。删除所属临时容器后另一 exec 已不可查询，记录保留未知退出码和输出缺口，凭原容器已消失的证据释放占用。
