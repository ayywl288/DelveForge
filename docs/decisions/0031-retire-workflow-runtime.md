# ADR-0031 退役旧流程运行时

状态为已接受。项目工作台与原发现、规划、演化、候选和交付流程有不同的授权模型、数据目录和执行环境。当前启动入口只装配工作台；继续构建另一条链路会保留无调用方的接口、迁移和模型依赖。

保留四个 Maven 模块及其依赖方向，发布单一宿主入口和 Vue 工作台。删除旧业务流程、API、Mapper、运行时镜像构建脚本、页面及只服务于它们的测试。工作台所需的消息协议、模型端口、实例锁以及 Docker/SQLite 适配器继续维护。使用 Spring JDBC 和 Flyway 管理 `control.db`，工作台 V1–V7 的迁移原样保留，V8 添加模型数据。

退役不需要执行 DROP、复制或重新解释既有用户数据。旧的 `data/delveforge.db`、交付目录及原始仓库由原主保管。此版本既不扫描旧数据库，也不把旧授权转换为项目写入权限。旧发行版本及其迁移可从 Git 历史取得。早期工作台的共享 Docker 环境与历史调用仍需按 ADR-0029 核对，因此保留该恢复路径。

继续并行维护旧模块会使两个入口同时承担发布和验证成本。把旧数据库迁入工作台则缺乏对话和执行权限的等价映射。独立退役允许工作台升级现有项目，同时保留原有数据的所有权与含义。
