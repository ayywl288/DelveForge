# ADR-0027：选定仓库作为任务输入与离线 Agent 执行

- 状态：Accepted，2026-11-08，依据本任务的明确用户授权。
- 取代 ADR-0006/0016/0017/0020/0025/0026 中与本决定冲突的活动仓库内容限制；历史证据不重写。
- 保持单 Agent、Plan/Step 授权、WorkingCopy 隔离、v8 事实证据、冻结重放与独立 Delivery。

## 问题与决定

非空 JWT 默认值曾使整份项目配置被投影剔除，随后 Agent 创建同路径文件又触发捕获拒绝。
读取、执行、修改和交付的不同规则制造了平台自身的冲突。固定公共仓库或配置文件白名单不能解决一般的选定输入问题。

用户选定快照中的普通文件统一为 SOURCE，包括 properties、YAML、环境示例、.npmrc、证书与密钥文件。
不根据键名、扩展名或秘密形态剔除文件、保护行或否决修改。文件工具返回准确源码片段，精确编辑不经过输出脱敏。
分析材料和运行日志仍可尽力净化；这不是保密保证，也不影响执行材料或修改资格。日志中的脱敏标记仍禁止作为新增源码写回。
运行确认处说明所选仓库内容可能进入模型、命令和日志，用户不应包含不愿暴露的有效凭据；不新增逐文件审批。

## 保留的边界与明确例外

选中快照不等于整台机器。平台 API 凭据、宿主凭据目录、Docker socket、正式 WorkingCopy 和无关用户文件不挂载或注入项目容器。
现有路径例外 `.git`、`.hg`、`.svn`、`.ssh`、`.aws`、`.gnupg`、`.m2` 目录仍拒绝，即使它们被提交到选中快照；
这会明确阻止该快照准入，不会悄悄省略其中的文件。它们保留为控制/宿主凭据命名空间；本任务不扩展其支持。
绝对路径、路径穿越、大小写冲突、链接、子模块、特殊类型、Git 内容转换、文件与总量预算继续校验。
二进制与超限文件可以按原字节参与执行，但现有文本编辑/冻结预算不因此扩大，不能交付不支持的改动。
已有 Maven 生成物准备和运行时依赖排除保持，并继续报告准备来源。历史 PUBLIC_RESOURCE/PRESERVED_ONLY 协议仍可读取。

## 网络与准入

隔离命令探针仍是启动前置条件。依赖网络准备的普通 Docker 操作失败或超时可退回 `--network none`；
缺少支持隔离桥网络的 Engine API 时也只允许离线路径。归属不明、隔离不成立、取消或无法停止已有资源仍失败关闭。
网络选择在本 Run 固定，避免每条离线命令再次触发同一准备失败。

能力报告分清 OFFLINE 与 CONTROLLED：前者没有下载能力；后者只证明固定 Maven/npm 代理已启动，未证明上游可达。
原固定上游、内部桥、代理、非 root、只读根、能力剥离、资源限制和无凭据注入保持。不开放任意外网或私有仓库。
需要下载时让实际命令返回真实失败与日志，Agent 在同一个循环中处理并解释。没有把成功启动代理描述为依赖就绪。

## 执行事实与失败现场

命令结果保存 invocationId、真实 exitCode、executionStatus、captureStatus、净化日志与 captureFailure。
命令运行后捕获失败通过专有异常携带受控结果，既有 TOOL_FINISHED 记录这些事实；不会当成命令未开始或自动重放。
捕获失败仍终止 Run，原始材料不是 Candidate，也不获得 Delivery 资格。

沿用 SQLite retained/occupied：进入 RUNNING 的同一事务先持久保留意图，再允许模型/工具写入；FINALIZING 保留同一意图。
安全 partial.diff 成功后可以清理运行资源，留下部分成果和诊断；捕获失败保留源卷及 Run 存储。
`retained=true` 表示仍有需保留的材料，可以是原始现场或成功捕获的非交付 partial；不等于 Candidate。
普通 FAILED 终态本身不能证明捕获成功。重启缺少该证明时保留原始材料；确认停止后可释放占用并允许新 Run。
成功 partial 清理后若 release 持久化失败，重启仍保留 partial，不重复删除材料；release 的 false 参数不能清除既有保留事实。
清理前先停止写入者并确认终态已持久；停止或持久化失败保留占用。重启协调先停止，再提交 INTERRUPTED，再读取保留事实，不能清掉 retained 材料。
成功冻结事务才解除原始现场保留。没有伪造状态、新存储表或新的恢复执行架构；不自动恢复旧对话。

## 循环与兼容

AgentProgress 比较命令诊断时忽略调用身份、时间戳前缀、结束时间和纯数字进度行。归一化耗时的范围为整行构建总耗时、带计数的测试汇总，以及 Surefire 以 `<<< FAILURE!` 或 `<<< ERROR!` 结尾的方法失败行。测试方法名、失败类型和断言正文中的时长按原值比较。
Infrastructure 在截断预览前用同一 Application 规则计算 `progressDiagnosticDigest`；比较时以它代替预览，原始 `diagnosticDigest` 不参与循环判断。
原始日志、原始摘要、退出码和检查事实不改写；没有比较摘要的命令结果按同样规则比较文本。错误、计数、位置与预览之外的新诊断仍参与比较。
同一短循环第二次重复时给出提示，第三次重复仍终止；源码修改重置计数。没有新增累计用量上限或完成合同。
v8 事实核验与 v1–v7 历史分支不变，过期源码的检查不变成最终验证。无源码修改的 NO_CHANGES 语义不变。
完整树扫描继续保留，本任务没有证据要求性能重写。

容器协议升级到 v10，旧镜像启动时明确拒绝，启动脚本和默认标签同步更新；证据仍为 v8。
没有新依赖、模块或领域状态。代价是用户选定的敏感文件不再享有旧内容过滤，失败现场也可能占用额外存储；
收益是输入完整、修改一致、离线工作可启动且失败事实与可恢复材料可追溯。
