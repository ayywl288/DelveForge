# ADR-0018：以实际进展驱动 Agent，启动前确认 API 费用

Status: Accepted by explicit user instruction on 2026-10-26.
Date: 2026-10-26

## 决策与责任边界

用户明确要求有意义的自主工作不因累计模型调用、工具调用、tokens 或固定总时长被终止。
移除这些运行配额及总计时器，保留真实用量遥测、逐操作技术超时、上下文/源文件/补丁/快照预算、
容器资源与网络隔离、取消、有限错误恢复以及重复无进展检测。不增加计费、余额或配额子系统。

前端每次启动或重试先显示外部 API 费用、必要仓库材料出站、无累计自动停止门槛及取消的费用含义。
用户必须主动勾选“有足够预算且愿意付费”，再确认开始。关闭、离开、切换 Plan/Step 后重置；
实际开始时仍复核当前资格与身份。API 必须收到 `paidUsageAcknowledged: true`，否则在任何 Run
预留或模型调用前返回 400 / PAID_USAGE_ACK_REQUIRED。该字段是启动请求的确认，不是余额证明或账单记录。
原 Step 确认、资产授权、WorkingCopy 可信版本及 Candidate/Delivery 状态边界另行保留。

Application 保留最近十二个结构化工具观察，比较工具名、参数及结果（忽略顶层 durationMs）。
长度一至四的相同循环连续出现三次、且无成功源码修改时，以 NO_PROGRESS 停止。
成功实际修改清空窗口；缓存中的旧修改结果不冒充新进展。不同参数或新结果不会因累计次数停止。
这是当前有界短循环启发式，不声称识别所有语义空转；既有重复补丁冲突与截断响应恢复上限不变。

Maven 检查继续有单次 check-seconds 超时；一次依赖准备上限为其三倍。HTTP 模型请求和 Docker/Git
控制仍有各自超时；取消会中断当前工作并由持久化终态、资源停止/清理事实完成确认。没有跨 Run 续跑。
用量缺报保持 unknown，数值表示溢出保持明确错误，不能回绕或伪造账单。费用以提供者实际账单为准。

## 取舍与验证

相对任意累计配额，当前方案允许长而有效的实现；代价是用户承担持续 API 费用并可随时取消。
相对完全放任循环，短窗口只停止可直接重复核对的无新事实循环；不引入通用语义进度评估器。
没有新增依赖、迁移或 Aggregate。Limits 仅保留技术操作/材料字段，旧累计配额和总时限配置退役。

回归覆盖超过历史 60/160 调用与 600K tokens 的持续新观察、相同及交替循环、真实修改重置、
时延变化不掩盖循环、取消、错误恢复、前端逐次预算确认/身份失效及 HTTP 未确认不预留 Run。
完整真实 FinTrack 与模型用量、官方交付和独立业务验收另行报告。
