# 产品

DelveForge 是一个在 Windows 本机使用的项目开发工作台。用户可以导入一个目录或创建空项目，在对话中请 Agent 理解代码、实施修改、验证行为或启动预览。用户随时可以打开项目工作副本，用自己的编辑器查看和接管文件。

一个 Project 持有一份独立、长期使用的工作副本和开发环境。项目下的 Conversation 分别保存用户要求、回复与执行证据，共享项目文件。发送消息可启动 Run、纠正正在运行的工作，或将任务加入队列。同项目串行执行，不同项目可并行。任务结果体现在工作副本、工具回执与对话答复中。

用户在输入框选择已配置的提供方、支持工具调用的模型及其思考强度。每次 Run 使用入队时的配置。用户可以查阅用量、停止或继续任务，并在任务结束后更换模型。解释、只读调查和代码修改都可以作为一次任务完成。
