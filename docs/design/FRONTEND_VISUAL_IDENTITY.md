## 框架与身份

石墨产品栏承载品牌、真实项目/阶段与连接状态。216px 浅灰蓝侧栏保留独立的深色当前项目卡，
显示项目名及已有 Plan 状态或画像版本。五阶段导航表示工作流位置，不等于完成百分比。
900px 以下导航折叠，页面仍显示项目身份；同阶段选择也关闭手机菜单并将焦点移回主内容。

1440px 桌面布局采用 216px 导航、工作区两侧各 28px 留白；内容列使用 `minmax(0, …)`。
中等宽度优先保护工作面，小屏堆叠而非缩小正文。不同任务的相邻列按内容保持高度，不为齐底填空白。

## 各工作面的布局与交互

| 工作面 | 保留的决策 |
|---|---|
| 项目 | 中文阶段由实际状态派生；真实已交付 Step / 总数及时间保留。移除五段装饰条，底部为继续入口，管理进入详情。 |
| 需求探索 | 左右角色气泡和 revision 笔记分工；实际 pending 请求显示文字和三点反馈。充分性只提示可以审阅，不制造百分比或自动结束探索。 |
| 画像审阅 | 六维集中阅读、逐项纠正，版本确认和继续探索清楚可见；未记录维度允许留空，手机收紧分区留白。 |
| 仓库理解 | 身份、完整路径和保存的分析 revision 并置；用途、技术、模块、能力、复用、风险及来源分区阅读。保存快照不冒充当前源码。 |
| 产品方向 | 候选索引在上，主论证配风险/依据栏。查看与正式选择分开，选择和拒绝各自确认。 |
| 演化规划 | 现状、目标与准备区配合连接 Step 时间线；范围、改动、前提和授权在对应 Step 内。已激活计划摘要有执行导航，准备不代替授权。 |
| 执行初始 | 没有 Run 时先显示 Step、授权/准备、环境、启动及费用，空运行记录为辅。 |
| 运行与终态 | 状态和停止在前，实际事件先于统计，配置为辅；代码与交付结果始终在下方，并提供跳转。Run、Frozen Candidate、Formal Delivery 分别表达。 |

正式文件列表来自已接受的 Step，Candidate 不冒充正式交付。冻结基线、预期 tree 和 SHA-256 可展开，
正式接受的 deliveryRevision / baselineRevision 可核对。测试证据按保存内容显示，`NOT_TESTED` 明确为未运行测试。
交付受阻或不明确不包装成成功；保留后端原因码，不从自由文本推断恢复授权。

## 视觉系统

`frontend/src/identity.css` 定义身份和壳层，`workflows-v2.css` 组织对话/仓库，
`decisions-v2.css` 组织方向/规划，`style.css` 保留共享控件基础。没有外部字体请求、主题切换或新增运行依赖。

| 角色 | 值 |
|---|---|
| 正文 / 产品栏 | `#252936` / `#20232E` |
| 画布 / 阅读面 / 导航 | `#F2F3F8` / `#FFFFFF` / `#E9ECF3` |
| 操作 / hover / 选中面 | `#4F58B8` / `#3D469D` / `#EEF0FC` |
| 次要文字 / 分隔 / 控件边界 | `#606A7E` / `#DFE3ED` / `#8B94A7` |
| 成功 | `#2C7152` on `#EDF7F1`，仅业务成功语义 |
| 警告 / 危险 | `#805619` on `#FFF7E8` / `#AD3442` on `#FFF1F2` |
| 活动区 | `#222632`，正文 `#EEF1FA`，次要文字 `#BBC4D9` |

正文使用 Segoe UI / PingFang SC / Microsoft YaHei；路径、revision 和数据使用 Cascadia Code / Consolas，
数字采用 tabular figures。页标题约 22–23px，内容标题 16–24px，阅读正文 14–17px，辅助信息 11–13px。
以 4px 为间距节奏，组内 8/12/16px，工作面间 20px，阅读区内留白 24/28px；手机按内容收紧。
明度、细边界和语义分组区分表面，主面板 8–12px 圆角、控件约 5px，不添加装饰渐变或玻璃面板。

Branch-to-Path 品牌几何表达既有起点、多个方向和明确选择。symbol、wordmark、primary-logo、
monochrome 与 favicon 使用同一构造，保持靛蓝/灰紫身份，不以标志替代产品界面。

## 可访问性与后续维护

保留原生按钮、对话框和 details、跳至内容、Escape 关闭与焦点返回。断点隐藏当前焦点时移向可见控件，
卸载时清理监听器。DOM 顺序随初始/运行任务切换，结果仍在事件之后。
深色项目卡焦点圈使用 `#C3C9FF`，浅靛蓝新流程说明使用 `#535D73`，不能只依据默认次要文字颜色。
主要手机按钮至少 44px；长路径、SHA、Evidence 来源与原始条目可换行或展开，Evidence 沿原分页。
等待反馈由真实请求状态驱动，减少动态效果时保留文字和静态圆点。

不为审美统一而合并选择、准备、Step 授权、费用确认、开始、停止或重新交付的业务边界。
复杂计划与技术证据仍需滚动；部分原因码缺少统一的用户语言映射，是已知局限，不据此新增恢复流程。
截图、浏览器测量与临时日志默认写入已忽略的 `target/frontend-visual-review/`；长期维护规范和可复用测试。
