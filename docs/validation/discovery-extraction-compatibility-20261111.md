## 修复结果与依据

课件 PDF、零散文档的普通回答。11次请求均为 HTTP 200 / `finish_reason=stop`，失败边界为
`PROFILE_EXTRACTION / INVALID_OUTPUT` 中的非字符串 `evidenceClaims` 元素。
原始模型响应未保留，本补丁使用合成形状回归，不声称重建原始 Payload。

六区仍是完整字符串数组，条数、长度、JSON 和领域值校验保持严格。辅助 `evidenceClaims`
仅保留最多64条、每条最多2048字符的非空文本，混入对象、数组、数字、布尔值或空值时忽略这些项；
整个字段缺失、null 或形状不可用也不单独否决有效分区。未使用的 `hasNewFacts` 提示不再参与拒绝决策。
没有将任意 JSON 字符串化，也没有用辅助说明授予覆盖权限。

实际分区有变化而缺少可用说明时，取**当前真实输入**中最多2048字符的连续原文作纪录依据，
保留完整本轮输入的 `sourceRef`、`sourceType=USER_INPUT`、`confirmed=false`；截取不拆开 Unicode 码点。
有效模型说明仍按原有方式展示并保持未确认。无有效分区变化不生成依据、不推进版本；
任一区需批准时整轮分区和关联依据均延后至批准提交。

提取提示增加无新事实、完整追加、替换旧目标及可选说明的 JSON 示例。对话提示通常要求一两句自然中文，
最多一个问题独立展示，普通回复不解释内部状态或术语；批准卡片负责差异与操作。
用户要求详细解释时保留必要说明，原2048字符输出边界未收紧，没有新增短字数失败门槛。
